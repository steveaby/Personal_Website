01 // OVERVIEW_&_MOTIVATION

Commuting between the University of Illinois Urbana-Champaign (UIUC) and major hubs like Chicago, O'Hare International Airport (ORD), and surrounding suburbs is a frequent challenge for students and faculty. Commercial rideshares are expensive, and public buses follow rigid schedules.

IlliniRide is a dedicated campus carpooling web platform designed to connect verified student drivers with riders traveling the same route to share rides, split travel expenses, and reduce transit friction safely.

02 // DATABASE_ARCHITECTURE_&_ADVANCED_PROGRAMS

Unlike typical apps that rely on bulky ORM layers, IlliniRide connects Node.js directly to a normalized MySQL 8.0 database engine executing compiled stored procedures and triggers for mission-critical operations:

  • Geospatial Dynamic Pricing Procedure (sp_post_ride_with_suggested_price): Computes coordinate distance between origin and destination cities in SQL and applies dynamic gas/distance formulas to recommend fair base prices.
  • Serializable Seat Booking Transaction (sp_book_ride_transaction): Executes booking creation within an ACID serializable transaction block, verifying vehicle seat capacity and preventing race-condition double bookings.
  • Automated Rating Recomputation Trigger (trg_reviews_after_insert_update_user_rating): Fires automatically upon review insertion to recalculate the reviewee's average rating in the Users table.
  • Relational Schema Normalization: 6 interconnected entities (Users, Vehicles, Cities, Rides, Bookings, Reviews) with foreign key cascading and consistency constraints.
03 // CORE_ENGINEERING_HIGHLIGHTS
  • Zero-ORM Latency Overhead: Direct execution of raw SQL queries via Node.js eliminates ORM mapping overhead and gives exact control over query execution plans.
  • ACID Concurrency Protection: Prevents overbooking scenarios when multiple riders attempt to reserve the last available seat simultaneously.
  • Full CRUD Capabilities: Comprehensive management interfaces for drivers to update vehicle details, publish routes, and riders to modify seat counts or cancel trips.
  • Cleaned Real-World Datasets: Pre-populated with verified Illinois city coordinate datasets and realistic commute itineraries.

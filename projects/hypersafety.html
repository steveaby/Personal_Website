01 // OVERVIEW_&_MOTIVATION

In healthcare facilities, research laboratories, manufacturing cleanrooms, and corporate offices, ensuring Personal Protective Equipment (PPE) compliance—specifically face mask adherence—is vital for biosecurity and occupational safety.

Manual compliance monitoring is labor-intensive, inconsistent, and impractical across large facilities. HyperSafety automates this workflow end-to-end: surveillance cameras continuously analyze video feeds, isolate human faces using deep learning Single Shot MultiBox Detectors (SSD), evaluate mask compliance via a custom 4-layer CNN, and cross-reference facial landmarks against employee records using 128-dimensional Euclidean embeddings to log violation warnings automatically in MySQL and push live alerts to supervisors via Flutter.

02 // TRI-SERVICE_MICROSERVICE_ARCHITECTURE

HyperSafety is engineered as a decoupled tri-service ecosystem spanning three repositories:

  • 1. Edge ML Vision Service (Python, PyTorch Lightning, OpenCV, Dlib): Processes video streams (live RTSP or video files via sk-video/cv2). Implements a two-stage computer vision pipeline: first localizing faces with a Caffe-based ResNet-10 SSD face detector (res10_300x300_ssd), then feeding cropped regions through a custom PyTorch Lightning MaskDetector CNN. Unmasked faces are identified using Dlib 128D facial feature vectors before dispatching HTTP/Socket events to the backend.
  • 2. Backend Telemetry Hub (Node.js, Express, MySQL, Imgur API): RESTful microservice running on port 7090. Manages administrative authentication via JWT, maintains an Employees relational schema in MySQL with warning counts and LastWarned timestamps, and features an automated Imgur OAuth token refresh worker (updateImgurAccessToken.js) to host employee avatar photographs in cloud storage.
  • 3. Mobile Supervision Client (Flutter & Dart): Cross-platform mobile application for facility managers. Features real-time employee compliance scorecards, photo capture via camera/gallery for onboarding new staff, warning count resets, employee deletion with administrative confirmations, and live incident telemetry.
03 // CORE_ENGINEERING_&_ALGORITHMIC_HIGHLIGHTS
  • Custom 4-Layer PyTorch Lightning CNN: Built with sequential Conv2d (32/64/128/256 feature maps), ReLU activations, MaxPool2d pooling, and Linear classification heads, trained with Adam optimization to achieve 98.95% validation accuracy.
  • 128-Dimensional Dlib Facial Recognition: Computes deep metric facial embeddings for registered staff and performs real-time Euclidean distance nearest-neighbor matching to identify unmasked personnel instantly.
  • Two-Stage Edge Pipeline: Decouples face localization (SSD ResNet-10 Caffe model) from mask classification and identity recognition, minimizing compute overhead on high-framerate video feeds.
  • Automated Cloud Image Lifecycle: Integrates Imgur REST APIs with automated background OAuth token rotation for scalable, zero-maintenance storage of employee reference photographs.

01 // OVERVIEW_&_MOTIVATION

Competitive Pokémon is a game of high-dimensional strategy, complex mathematical damage formulas, and predicting an ever-shifting competitive metagame. Building a top-tier roster manually requires countless hours of manual calculations and spreadsheet analysis.

BugCatcher Joey was built for HackIllinois 2026 as an automated AI Strategist that takes any player-crafted team and rigorously stress tests it against top-tier competitive Smogon OU metagame threats. Rather than relying on simple static tier lists, Joey performs parallelized Monte Carlo simulations to mathematically identify defensive holes, EV inefficiencies, and move pool blind spots.

02 // SYSTEM_ARCHITECTURE_&_HYBRID_PIPELINE

The project leverages a decoupled, high-performance hybrid architecture across three layers:

  • Reactive Glassmorphism Frontend (React 19 & Vite): Interacts with the PokeAPI for live sprite and stat fetching, and features Framer Motion animations for simulated battle turns.
  • Serverless Compute Cluster (Modal Cloud): Deploys containerized Python FastAPI microservices on Modal. Modal dynamically provisions isolated cloud containers, pulling the heavy @smogon/calc Node.js mathematical engine to run thousands of damage calculations in parallel.
  • AI Strategist Agent (OpenRouter LLM Integration): Synthesizes quantitative simulation data into actionable competitive recommendations and tactical insights for the trainer.
  • Showdown Syntax Exporter: Automatically converts the AI-optimized team into standard Pokémon Showdown export format ready for tournament play.
03 // CORE_ENGINEERING_HIGHLIGHTS
  • Monte Carlo Tree Search (MCTS): Evaluates branching probability trees across potential lead match-ups, weather conditions, entry hazards, and status conditions to discover statistically dominant sequences.
  • Automated OHKO Breakpoint Discovery: Computes exact EV spreads required to survive key metagame attacks and achieve guaranteed one-hit or two-hit knockouts (OHKO/2HKO).
  • Dynamic Meta Countering: Analyzes user-selected rosters against prevailing tier threats to suggest optimal item replacements (Choice Specs, Focus Sash, Heavy-Duty Boots) and coverage moves.
  • Zero-Cold-Start Cloud Architecture: Modal's serverless infrastructure auto-scales worker containers on demand without ongoing idle server costs.

01 // OVERVIEW_&_MOTIVATION

Modern sports broadcasting dashboards are notoriously bloated, rigid, and one-size-fits-all. Casual fans get overwhelmed by walls of dense tabular numbers, while analysts and bettors struggle to extract high-leverage data in real-time.

SidelineSight solves this by introducing a cognitive-adaptive live sports telemetry architecture. Instead of static HTML pages that refresh periodically, SidelineSight streams sub-15ms WebSocket state frames directly into an intent-driven interface that dynamically adapts its layout, widgets, and visual hierarchy to match the user's primary viewing objective (Study, Player Tracking, Betting Intelligence, or Minimal Floating Scoreboard).

02 // SYSTEM_ARCHITECTURE_&_DATA_PIPELINE

The platform is structured into a decoupled, real-time client-server architecture:

  • High-Concurrency Streaming Server (Python FastAPI & Uvicorn): Ingests live ESPN feed schemas, synthesizes microsecond game events, and broadcasts state frames over persistent bidirectional WebSockets.
  • Coordinate Transformation Pipeline: Normalizes raw 2D coordinate telemetry into mathematically precise SVG viewBox coordinate systems for hardwood basketball courts and NHL hockey rinks.
  • Reactive Client Engine (Next.js 16 App Router & React 19): Utilizes custom WebSocket connection state hooks with automatic exponential backoff reconnection, local memory caching, and Framer Motion 12 hardware-accelerated animations.
  • Resilient Offline Caching: Roster datasets, team color schemes, and player headshots are stored locally with memory fallback, preventing UI stutters during intermittent network drops.
03 // CORE_ENGINEERING_HIGHLIGHTS
  • Dynamic SVG Shot Coordinate Mapping: Renders vector-accurate basketball shot arcs (makes, misses, blocked attempts) and hockey puck trajectories in real-time without canvas repaint bottlenecks.
  • Game State Momentum Reordering: Evaluates score differentials and clock leverage to automatically prioritize clutch fourth-quarter possessions over routine early-game stats.
  • 4 Cognitive Intent Layouts: Dynamically morphs the interface between Study Mode (deep statistical radar), Player Tracking (usage & +/- efficiency), Betting Insights (live spreads & moneyline momentum), and Floating Scoreboard (ultra-low footprint).
  • Multi-League Dual Engine: Handles distinct sport rules, period clocks, penalty kill timers, and box scores across both the NBA and NHL simultaneously.
